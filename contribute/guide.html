Contributing guide

How wework.

Everything you need to get a change merged into any Pvot repo. It is short on purpose.

{% include contribute-nav.html %}

Before you start

  • Find the repo on the where to contribute page, and check its open issues and the public tracker so you do not duplicate work.
  • For anything bigger than a fix, say what you plan on Telegram or in an issue first. It saves you rewriting it later.
  • Be kind. Everyone here is giving their own time.

Building an app

New apps are Kotlin and Jetpack Compose, built on PvotLib. Use its components, tokens and glass rather than rolling your own, so the app looks and moves like the rest of Pvot. PvotLib's guide covers the theme, motion and every component, and its docs explain how to start a new app or move an existing one over.

Submitting a change

  1. Fork the repo and branch from main: git checkout -b fix/short-description.
  2. Keep commits focused, with messages in the imperative mood, like Fix crash when sharing a photo.
  3. Sign off every commit with git commit -s. CI checks the Developer Certificate of Origin on every pull request.
  4. Add licence headers. New files carry SPDX headers (SPDX-FileCopyrightText and SPDX-License-Identifier), and CI runs a REUSE check.
  5. Run pre-commit where a repo has it. It trims whitespace, checks YAML, and formats Kotlin.
  6. Test on a device before you open the pull request, and say what you tested on.
  7. Open the pull request with what changed and why. Screenshots for anything you can see, logs for anything that broke.

Reporting bugs

Open an issue on the app's repo or the public tracker with your device, Android version, app version, the steps to reproduce, and a logcat if you can get one. A clear report is real help.

Privacy rules for code

  • No analytics, ad, or tracking SDKs, ever. Exodus scans what we ship.
  • Ask only for the permissions a feature needs, and say why in the pull request.
  • Keep data on the device unless the user asked for it to go somewhere.

Code you contribute is released under the repo's licence, Apache-2.0 for most of Pvot. Thanks for helping build it.
