Contribute

Build it with us.

Pvot is volunteer-run and fully open. Whether you write Kotlin, design interfaces, or just file a sharp bug report, there is a place for you. No permission needed.

Where to jump in

code

Build an app

Pick an app, open a pull request. Everything is Kotlin and Jetpack Compose, built on PvotLib.

 palette

Grow the design system

PvotLib always needs more components, tokens, and polish. Every improvement lands in every app.

 bug_report

Report a bug

Found something broken? Open an issue with your device, steps, and logs. Triage is real help.

 favorite

Test and translate

Flash builds, report regressions, or translate an app. Say hi on Telegram and we will point you somewhere.

Before you start

  • Fork the relevant repo under github.com/PVOT-OSS and branch from there.
  • Keep pull requests focused, with clear commit messages.
  • Build on-device before you open a PR where it matters.
  • Be kind. We are all here on our own time.

New to open source? That is fine. Reach out on Telegram and someone will help you land your first change.
